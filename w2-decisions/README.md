# Неделя 2 · «Чат проекта → журнал решений»

Синтетический рабочий чат студии «Север» (5 человек, 01–30.09.2026, 191 сообщение), журнал решений по нему и сверка журнала с ключом ответов.

## Как делал

1. **Критерий и легенда — до чата.** Сначала записал ключ: 9 решений, из них 2 позже отменены и 1 принято без слова «решили», плюс 2 темы без итога и 3 ловушки. Это [`answers/criteria.md`](answers/criteria.md) и [`answers/legend.json`](answers/legend.json).
2. **Чат.** Его по легенде развернул отдельный агент. Потом я переписал в нейтральные несколько сообщений, где генератор добавил решения сверх легенды (номера, авторы и время остались прежними).
3. **Инструкция.** [`INSTRUCTION.md`](INSTRUCTION.md) — по ней журнал можно собрать заново. Правила в ней нейтральные, без примеров, похожих на ключ.
4. **Журнал.** Его собрал «слепой» агент: у него были только `INSTRUCTION.md` и `chat.md`, к ключу доступа не было. Результат — [`journal.md`](journal.md). **Ручных правок журнала: 0.**
5. **Сверка.** Скрипт [`sverka.py`](sverka.py) сравнивает журнал с ключом, результат — [`answers/sverka.md`](answers/sverka.md).
6. **Проверка сверки.** Скрипт [`porcha.py`](porcha.py) портит журнал по одному признаку за раз и смотрит, заметит ли сверка, — [`answers/porcha.md`](answers/porcha.md).

## Итог

- **Найдено:** все 9 решений ключа, тип и статус у каждого верные. Неявное решение распознано, обе темы без итога попали в список, ни одна ловушка не попала в журнал. Цитата и время сверены с чатом во всех 14 строках.
- **По порогу критерия пройдено 6 проверок из 8.** Не пройдено:
  - в журнале 5 лишних строк;
  - одна отмена отнесена не к тому сообщению.
- **Разбор расхождений** (подробно — в разделе 6 файла `answers/sverka.md`):
  - явные ошибки агента — 2 строки;
  - остальное — спорные случаи, где неточен сам ключ или в чате остался след генератора.

  Ключ после сверки не менял.
- **Тест порчи:** сверка ловит все 20 порч журнала. Первый прогон поймал 18 — дыры закрыты проверкой формы журнала. Ограничения теста описаны в `answers/porcha.md`.

## Как повторить

Нужен Python 3, без внешних библиотек.

```
python3 sverka.py chat.md journal.md answers/legend.json answers/sverka.md
python3 porcha.py chat.md journal.md answers/legend.json answers/porcha.md
```

- `sverka.py` пишет отчёт сверки. Код выхода 1 значит, что есть расхождения.
- `porcha.py` портит копию журнала (сам журнал не трогает) и для каждой порчи пишет, заметила ли её сверка.
- Ручные разделы отчётов при перезапуске сохраняются.

Чтобы проверить свой журнал, соберите его по `INSTRUCTION.md` и подставьте вместо `journal.md`.
