# Инструкция: собрать журнал решений по рабочему чату

Инструкция для агента (или человека). Входные данные — только файл чата, путь к нему задаётся при запуске:

```
CHAT = <путь к chat.md>
OUT  = <путь к journal.md>
```

Других файлов не открывай: журнал строится только по тексту чата.

## 1. Формат чата

Строка сообщения:
`[NNN] ДД.ММ.ГГГГ ЧЧ:ММ · Имя: текст (в ответ на [NNN])`

Реакции — отдельной строкой с отступом под сообщением: `      реакции: 👍 Имя, Имя`.
«Сегодня» для журнала — дата последнего сообщения в чате.

## 2. Что считать решением

Решение — договорённость, которая меняет, что команда делает дальше, и которую принял человек, вправе её принять (или команда в целом). Кто за какую область отвечает — определяй по самому чату.

**Явное решение** — итог прямо зафиксирован в сообщении.

**Неявное решение** — итог прямо не назван, но команда его приняла. Записывай такое решение, только если в чате есть подтверждение принятия (реакции, отсутствие возражений, последующие действия по нему) и укажи эти подтверждения в разделе 5.2.

**Не решение** (в журнал не попадает):
- высказывание, которое не было всерьёз;
- предложение или мнение, которое не приняли;
- заявление человека вне его полномочий, которое ответственный не поддержал;
- личная рабочая мелочь, не меняющая планы команды;
- тема без итога — она идёт в раздел 5.3.

## 3. Отмены и замены

- Отмена — не отдельная строка, а отметка в строке исходного решения: статус «отменено», в «чем отменено» — номер сообщения и автор.
- Отмена может быть и не названа прямо — оценивай по смыслу, действует ли решение после этого сообщения.
- Решение, принятое вместо отменённого, — отдельная строка.

## 4. Время и цитата

- «Когда» — дата и время сообщения, в котором решение принято (для неявного — сообщение, где появилось принятое предложение), а не срок или дата, о которой говорится в решении.
- «Цитата» — дословный фрагмент этого сообщения, без пересказа, 5–25 слов. Номер, время и автор в строке совпадают с этим сообщением.

## 5. Что сдать (OUT)

Markdown-файл из четырёх разделов.

### 5.1 Таблица решений

| id | Что решили | Кто | Когда | Сообщение | Цитата | Тип | Статус | Чем отменено |
|---|---|---|---|---|---|---|---|---|
| D1 | … | Имя | ДД.ММ.ГГГГ ЧЧ:ММ | [NNN] | «…» | явное / неявное | действует / отменено | [NNN], Имя — кратко как |

- id — D1, D2, … по порядку времени.
- Статус — на «сегодня» (дата последнего сообщения).
- «Чем отменено» — пусто, если решение действует.

### 5.2 Неявные решения: на чём держатся
Для каждого неявного решения: id, сообщение с предложением и подтверждения (реакции, отсутствие возражений, номера сообщений, где решение уже исполняется).

### 5.3 Обсуждали, но не решили
Список тем: что обсуждали, номера ключевых сообщений, чем закончилось (отложили / заглохло / спор без итога).

### 5.4 Ответы на проверочные вопросы
1. Какие решения действуют на сегодня (id).
2. Для каждого отменённого решения: кто и каким сообщением его отменил.
3. Какие решения приняты без явной фразы.
4. Что обсуждали, но так и не решили.
5. На чём держится каждая строка: есть ли у неё цитата и время сообщения (подтверди по каждой строке).

## 6. Самопроверка перед сдачей

- Каждая цитата дословно есть в тексте сообщения с указанным номером.
- Время и автор в строке совпадают с этим сообщением.
- У каждого отменённого решения заполнено «чем отменено», у действующих — пусто.
- Каждая строка таблицы проходит определение решения из раздела 2.
- Отмена не записана отдельной строкой.
